# 本周网文市场分析报告

## 本周概览

本周我们以 120 本样本作品为分析基底，提取 TF-IDF 关键词 2000 个，覆盖流派标签关联书目 2382 本，力图从题材、人设、金手指与世界观四个维度，勾勒当下网文市场的最新脉动。

整体市场情绪可用八个字概括：**穿越为骨，系统为魂**。“穿越”以 1439 次词频、0.0379 的 TF-IDF 值高居全站关键词榜首，其权重几乎是第二名“系统”（637 次）的两倍。这说明穿越已不再是某个具体流派，而是沦为一种近乎默认的叙事底层逻辑——它不再提供新鲜感，而是承担着“让读者快速代入”的通道功能。与此同时，“觉醒”“重生”“开局”等词汇的活跃，暗示市场对“高概念、快节奏、强钩子”的开篇需求仍在持续攀升。

## 题材风向

从流派标签排行看，**穿越（37 本）、都市（27 本）、轻小说（25 本）、玄幻（23 本）、仙侠（22 本）** 构成第一梯队。穿越与都市、轻小说的交叉，正在催生一种“轻量级穿越”亚类型——不再强调回到过去改变历史，而是穿越作为进入异质空间的门票，服务于都市日常或轻小说式的人际关系展开。

共现数据揭示了更有价值的信号：**“穿越+系统”以 244 次的共现量遥遥领先**，构成当前网文最稳固的类型骨架；“修炼+穿越”（132 次）紧随其后，表明仙侠修炼体系仍是穿越题材的重要落点。值得注意的是，**“穿越+苟道”（43 次）** 这一组合虽绝对数量不大，却代表了一种反英雄、反爽感的审美偏移——主角以“苟住”为生存哲学，与传统的“无敌流”（46 次）形成微妙对冲。此外，“灵异+穿越”（70 次）与“星际+穿越”（44 次）的活跃，说明灵异复苏与星际科幻正在成为穿越题材的新容器。

世界观关键词方面，“朝堂”（6 次）与“修真”（6 次）并列榜首，但“永夜”“黑暗”“仙朝”“功名”等词的出现，透露出读者对**具有压迫感的世界观**——无论是朝堂权谋的窒息感，还是永夜废土的绝望感——正在产生新的兴趣。

## 人设与金手指趋势

主角人设分布呈现出明显的**“去天才化”与“去无敌化”** 倾向。穿越者（41 人）占据绝对主流，但“其他”（32 人）与“普通人生存”（18 人）合计 50 人，超过了传统天才流（8 人）、无敌流（4 人）、废柴逆袭（3 人）的总和。这说明市场正在从“主角必须特殊”向“主角可以普通，但处境必须特殊”迁移。重生复仇（13 人）保持稳定基本盘，而“苟道稳健”虽仅 1 人，却是一个值得追踪的种子信号——它呼应了读者对“低风险生存”的心理需求。

金手指方面，**“无/未提及”以 59 本占据近半壁江山**，这是一个极易被忽视却至关重要的数据。它意味着超过四成的作品不再依赖显性金手指来驱动叙事，而是将“穿越”本身或“重生知识”（22 本）作为隐性优势。系统（13 本）虽仍是第一大显性金手指，但其占比已远低于市场直觉。特殊血脉（5 本）与传承/老爷爷（4 本）的边缘化，进一步印证了**“金手指内化”** 的趋势：读者不再满足于外挂式的爽感，而更青睐主角凭借认知差、信息差或性格特质在复杂世界中周旋。

## 创作建议

**第一，做“穿越+X”的减法，而非加法。** 数据表明，穿越与系统的叠加已过度饱和（244 次共现）。建议创作者将穿越作为背景设定而非核心卖点，把叙事重心转移到具体的生活质感或专业领域上。例如“穿越+年代文”（已有 2 次世界观关键词出现）或“穿越+美利坚”（2 次），通过穿越带来的认知错位制造戏剧张力，而非依赖系统面板。

**第二，拥抱“普通人生存”人设，但为其配备“非普通困境”。** 18 本“普通人生存”类作品的存在，说明读者对“凡人流”有真实需求。关键在于：主角可以没有金手指，但必须被抛入一个道德灰度极高、选择代价极大的情境中。朝堂权谋（6 次）与永夜黑暗（2 次）世界观的活跃，正是这类叙事的理想土壤。

**第三，关注“苟道”与“稳健”的审美红利。** 尽管目前仅 1 本明确标注“苟道稳健”，但“穿越+苟道”共现 43 次，说明这一审美已具备一定的读者基础。建议尝试“苟道+仙侠”或“苟道+朝堂”的组合，以“不争而争”的生存智慧替代传统的打怪升级，用信息差与策略博弈构建爽点。这或许是下一阶段差异化竞争的关键切口。
