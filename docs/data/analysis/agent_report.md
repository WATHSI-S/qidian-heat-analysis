## 本周概览

2026-W43 周，起点中文网榜单共覆盖 **1460 个榜单条目、715 本独立作品、651 位独立作者**，横跨 **14 个品类**。八大榜单（月票、畅销、阅读指数、推荐、收藏、书友、更新、签约新书）各收录 180 本作品，签约新书榜以 200 本略多，说明平台仍在持续为新品供给曝光位。榜单去重后独立作品数（715）与榜单条目数（1460）之比接近 1:2，意味着**头部作品普遍是"多榜通吃"型选手**——一本强书同时占据月票、畅销、阅读、推荐四榜，马太效应明显。

本周整体市场情绪**偏热、偏集中**。头部由辰东《夜无疆》、季越人《玄鉴仙族》、熊狼狗《没钱修什么仙？》、会说话的肘子《青山》等几本"钉子户"作品牢牢把持，几乎在所有核心榜单前五反复出现。与此同时，榜单换血率高达 **77.9%**（对比 W42，新增 302 本、消失 236 本、仅 455 本留存），说明腰部与长尾竞争极其激烈，**"周更即生死"**的残酷节奏仍在延续。

从热度绝对值看，玄幻（34.75）、都市（23.20）、仙侠（22.23）、轻小说（21.73）构成四大主力盘，合计占据榜单大半江山。本周的显著特征是：**玄幻、轻小说双双走强，都市、诸天无限明显回落**，市场正在从"都市现实向"向"高幻想、强设定"方向摆动。

## 题材风向

**玄幻重回强势，创下近半年新高。** 玄幻本周热度 34.75，较上周 +2.28，不仅稳居品类第一，更是 22 周以来（W22 起）的最高值，超越了此前的峰值 W37（33.82）。这一轮上涨由头部驱动：《夜无疆》（辰东）霸榜月票、阅读、推荐三榜第一，《青山》《剑烛大荒》《让仙门再次伟大》《武道！》等形成密集矩阵。值得注意的是，畅销榜第一竟是**完本作品《苟在初圣魔门当人材》**（鹤守月满池），说明"完本老书"仍在持续产生商业价值，长尾变现能力不容小觑。玄幻的强势，本质是**头部作者 IP 号召力 + 经典套路稳定复购**的双重结果。

**轻小说稳步上行，二次元向内容持续渗透。** 轻小说本周热度 21.73（+2.08），从 W41 的低点 19.09 连续两周反弹。榜单上《神宠供应商》（轻泉流响）位列书友榜第一、畅销第 11，《还不起学贷的我只好兼职猎魔》《姐姐，我也要一起当女仆吗？》等作品同时出现在月票与阅读榜。更新榜中《龙族：从EVA归来的路明非》《东京：这家昭和居酒屋全是修罗场》《从地错开始的诸天之旅》等**同人/日系题材**密集出现，显示轻小说正在向"IP 同人 + 日式日常"细分扩张。

**都市与诸天无限双双回落，需警惕。** 都市本周 23.20（-1.89），是本周跌幅最大的品类；诸天无限 3.31（-1.56），从 W42 的短期反弹（4.87）迅速回落。都市虽仍有《请勿高考时渡劫》《1984：从川菜馆开始》《捞尸人》等强书支撑，但整体热度已从 W22 的 32.9 高点持续下移，呈现**"头部稳、腰部散"**的疲态。诸天无限则是典型的"高波动小品类"，其涨跌更多受个别作品进出榜影响，不宜过度解读趋势。

**值得关注的潜力品类：武侠、体育、现实、悬疑灵异。** 武侠虽体量小（1.98），但本周 +0.74，涨幅居前，更新榜第一《天残殇》即为武侠，或预示一波"复古武侠"回暖；体育（+0.47）、现实（+0.26）虽基数低但方向向上；悬疑灵异（+0.29，热度 2.89）在《诡异搜打撤》《捞尸人》等"诡异+搜打撤"新玩法带动下稳步爬升，是**低成本试水、高上限爆发**的品类。相对地，历史（-0.95）、科幻（-0.48）小幅回落，但历史仍凭《廓晋》《绍宋》稳居前五品类，基本盘扎实。

## 关键词与流派洞察

**TF-IDF 关键词揭示"穿越+系统+觉醒"仍是创作第一母题。** 本周关键词榜首"穿越"权重 0.0382、频次高达 1537，遥遥领先；"系统"（682）、"觉醒"（510）、"重生"（342）紧随其后。这构成了一条清晰的**"开局设定公式"**：穿越打底 → 系统/金手指赋能 → 觉醒/重生提供爽点。此外，"修仙"（243）、"斗罗"（152）、"武魂"（149）、"大陆"（148）等词高频出现，说明**斗罗/玄幻世界观模板**仍有大量作者在套用；"开局"（201）、"天赋"（199）、"金手指"（146）则进一步印证"开局流"与"天赋流"是当下最主流的开篇打法。

**流派标签呈现"一超多强"格局，穿越是绝对中枢。** 在 2526 本带标签作品中，"穿越"以 1345 次出现，占比过半，是名副其实的"万能标签"。共现关系更能说明问题：**"穿越+系统"共现 263 次**，是最高频组合，构成当前网文最主流的"黄金搭档"；"修炼+穿越"（138）、"灵异+穿越"（78）、"系统+重生"（68）、"游戏+穿越"（58）依次排开。这提示创作者：**穿越已从"题材"退化为"基础设施"**，真正的差异化不在"是否穿越"，而在穿越之后叠加什么——是系统、灵异、游戏还是苟道。

**细分流派暗流涌动，"苟道""无敌流""家族""灵气复苏"值得布局。** 标签频次中，"苟道"（85）、"无敌流"（96）、"家族"（84）、"种田"（66）、"权谋"（51）、"灵气复苏"（50）等显示出读者口味的细分：一方面"苟道+穿越"（44）、"修炼+家族"（31）等组合反映**稳健发育流**受青睐；另一方面"无敌流+穿越"（48）代表**爽感直给流**同样有市场。结合《玄鉴仙族》（家族修仙）、《我在永夜打造庇护所》（种田/庇护所）等头部作品，"家族流""庇护所流"正从小众走向主流，是本周最值得押注的结构性机会。

## 创作建议

**1. 玄幻赛道"稳中求变"：用经典世界观 + 新结构切入。** 玄幻本周创半年新高，但头部被大神垄断，新人硬拼纯套路难出头。建议借"家族流""庇护所流""种田发育流"等新结构，套用成熟的玄幻/修仙世界观——如《玄鉴仙族》的家族修仙、《我在永夜打造庇护所》的末世庇护所，都是"老题材+新玩法"的成功范式。开局可用"穿越+系统"保底，但要在第三章前亮出差异化机制。

**2. 轻小说抓住"同人 + 日系日常"红利窗口。** 轻小说连续两周回暖，更新榜同人/日系题材密集。有 IP 认知基础的作者可切入《龙族》《火影》《地错》等成熟同人，或走"东京居酒屋""女仆"类日式日常甜宠路线。该赛道读者黏性高、竞争相对玄幻温和，适合中小作者积累第一批铁粉。

**3. 谨慎进入都市与诸天无限，或转向"都市+超自然"混合。** 都市热度持续走低、诸天无限高波动，纯都市现实向已显疲态。若要布局都市，建议叠加灵异/悬疑/超自然元素（如《捞尸人》《诡异搜打撤》），走"都市皮、诡异骨"的混合路线，既能借都市基本盘，又能吃到悬疑灵异上升红利。

**4. 押注"苟道/稳健发育"与"悬疑灵异"两个上升细分。** "苟道"标签 85 次、与穿越共现 44 次，反映读者对"稳扎稳打、扮猪吃虎"叙事的偏好正在上升；悬疑灵异品类热度稳步爬升且体量小、天花板高。建议新书在开篇即确立"苟"或"诡异"的差异化调性，用低成本试水博取高弹性回报。

## FAQ

**Q: 本周哪个品类最值得新人入场？**
A: 轻小说和悬疑灵异。轻小说连续两周回暖、竞争相对温和、读者黏性高；悬疑灵异体量小但稳步上升，天花板高，适合低成本试水。玄幻虽最热但头部垄断严重，新人硬拼难度大。

**Q: "穿越"题材是不是已经饱和、不该再写了？**
A: 不是饱和，而是"基础设施化"。穿越标签出现 1345 次、占比过半，它已从"卖点"变成"默认设定"。关键不在是否穿越，而在穿越后叠加什么差异化元素（系统、灵异、苟道、家族等）。

**Q: 当前最主流的开篇公式是什么？**
A: "穿越 + 系统 + 觉醒/重生"三件套。关键词榜"穿越"(1537)、"系统"(682)、"觉醒"(510)、"重生"(342) 依次领先，"开局""金手指""天赋"高频出现，说明"开局流+天赋流"是当下最主流的开篇打法。

**Q: 玄幻本周为什么这么火？还能持续吗？**
A: 玄幻热度 34.75 创 22 周新高，由辰东《夜无疆》、会说话的肘子《青山》等头部矩阵驱动，叠加经典套路稳定复购。头部 IP 号召力强，短期仍会维持强势，但腰部竞争激烈、换血率高，持续性取决于头部作品更新节奏。

**Q: 都市题材是不是在走下坡路？**
A: 本周都市热度 23.20、跌 1.89，为跌幅最大品类，且从 W22 的 32.9 高点持续下移，呈"头部稳、腰部散"的疲态。纯都市现实向确实走弱，建议转向"都市+灵异/悬疑"混合路线。

**Q: 完本老书还有商业价值吗？**
A: 有，而且很大。本周畅销榜第一是完本作品《苟在初圣魔门当人材》，收藏榜前五几乎全是完本经典（《诡秘之主》《斗破苍穹》《绍宋》等）。完本长尾变现能力强劲，说明经典 IP 有持续复购价值。

**Q: "苟道流"和"无敌流"哪个更有市场？**
A: 两者并存、各有拥趸。"无敌流"（96 次）代表爽感直给，适合快节奏读者；"苟道"（85 次，与穿越共现 44 次）代表稳健发育、扮猪吃虎，读者偏好正在上升。新人可根据自身笔力选择，苟道流对节奏把控要求更高但差异化更强。

**Q: "家族流"是本周的新机会吗？**
A: 是的。家族标签 84 次，"修炼+家族"共现 31 次，头部《玄鉴仙族》正是家族修仙代表作并稳居月票/阅读前列。家族流正从小众走向主流，是玄幻/仙侠赛道值得布局的结构性机会。

**Q: 榜单换血率 77.9% 意味着什么？**
A: 意味着腰部与长尾竞争极其残酷——本周新增 302 本、消失 236 本，仅 455 本留存。作品必须保持稳定高质量更新才能留在榜上，"周更即生死"。对新人而言既是压力，也是靠稳定更新弯道超车的机会。

**Q: 同人题材（龙族、火影、地错等）值得写吗？**

**Q: 哪些品类本周在回落，应该避开？**

**Q: 头部作品"多榜通吃"对中小作者有何启示？**
