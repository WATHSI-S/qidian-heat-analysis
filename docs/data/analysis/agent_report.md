## 本周概览

**2026-W33** 起点中文网排行榜共收录 **1260 本书籍**，涉及 **588 位独立作者** 与 **14 个品类**。在品类数量上，**都市（251本）、轻小说（232本）、玄幻（219本）、仙侠（170本）、历史（129本）** 构成第一梯队，五大品类合计占据总书量的近八成。都市与轻小说的体量已反超传统霸主玄幻，反映出平台内容结构向"现实题材+二次元"双轮驱动的深度迁移。

从周间流动看，本周相较上周（W32）**换手率高达 65.4%**——共同在榜书籍仅 463 本，新增 224 本、消失 228 本。这一极高的换手率说明榜单竞争异常激烈，新作涌入凶猛，也意味着读者对新鲜内容的渴求极强，市场处于快速迭代期。整体市场情绪偏乐观且充满变数：头部作品（捞尸人、玄鉴仙族、夜无疆）地位稳固，中腰部作品则每周大洗牌。

**历史品类热度单周暴涨 2.11（11.46→13.57）**，成为本周最大黑马；轻小说、武侠、科幻同步上行。而玄幻（-1.86）、仙侠（-1.89）两大传统霸主则双双遇冷，出现明显回落。这一"传统题材降温、多元题材升温"的态势，是本周最值得创作者关注的结构性信号。

## 题材风向

**热门品类的此消彼长**：玄幻与仙侠作为起点两大传统支柱，本周热度同时下滑近 2 个点，是 12 周来的低位。玄幻在月票榜虽仍占据多数席位（夜无疆、星河之主、剑烛大荒、青山、让仙门再次伟大），但整体大盘走弱，说明头部集中、腰部空心化。仙侠则在月票榜强势（玄鉴仙族、没钱修什么仙），但整体数量从 182 降至 170，呈现"精品化、头部化"而非规模化扩张。

**历史题材强势崛起**：历史品类以 +2.11 的单周增幅领跑全场，热度从 11.46 跃升至 13.57。榴弹怕水的《廓晋》同时登上月票榜、畅销榜、阅读指数榜，其完本旧作《绍宋》也稳坐收藏榜与阅读指数榜。这表明"历史+权谋+家族"的严肃向创作正获得读者高度认可，历史题材不再是冷门小众，而是被头部作者带火的新增长极。

**新兴题材的爆发点**：武侠品类本周持续升温（+0.73，连续数周上扬至 2.25），虽绝对体量仍小，但增速亮眼。轻小说在书友榜、更新榜表现活跃——"以一龙之力打倒整个世界"、"姐姐，我也要一起当女仆吗"、"战锤：女原体"等作品集中上榜，二次元、玩梗、轻松搞笑的创作风格大行其道。科幻方面，远瞳新作《异度旅社》登上推荐榜，科幻热度温和回升。

**值得关注的品类**：历史、武侠、轻小说是当前热度上升最快的三个方向。而体育（-0.61）、军事（-0.11）、现实（-0.15）、诸天无限（-0.28）则持续走弱。尤其诸天无限已连续多周在 3-4 区间徘徊，从 12 周前的 6.82 高位大幅回落，该题材热度明显衰退，创作者需谨慎入场。

## 关键词与流派洞察

**TF-IDF 关键词反映的创作热点**：本周词频最高的关键词是 **穿越（1097次）、系统（516次）、觉醒（386次）、重生（268次）**，构成当下网文创作的核心母题。"时代""未来""一年"等时间向词汇高频出现，与历史题材的崛起（"重回1983""1984"等年代文）遥相呼应。"开局""奖励""天赋""发现自己"等词汇则指向"开局流""金手指流"的持续流行。值得注意的是 **"斗罗""武魂"** 进入关键词榜，反映出斗罗同人/衍生创作的热度。

**流派标签的分布变化**：流派标签中，**穿越（947）、系统（405）、重生（255）** 稳居前三，与关键词高度吻合。但更具洞察力的是细分流派的涌现：**灵异（203）** 异军突起，这与《捞尸人》霸榜月票、畅销双第一直接相关，都市灵异/悬疑风格正当风口；**苟道（74）**、**种田（50）**、**家族（61）**、**权谋（44）** 等"稳健流""经营流"标签集中出现，呼应历史题材的家族、权谋创作；**学院（97）**、**星际（85）**、**无敌流（76）**、**洪荒（65）** 等也保持一定热度。

**标签共现关系**：共现数据显示 **"穿越+系统"（193次）** 是最主流组合，**"修炼+穿越"（105次）**、"系统+重生"（60次）、"灵异+穿越"（59次）紧随其后。尤其 **"灵异+穿越"** 与 **"穿越+苟道"（39次）** 的组合，印证了都市灵异与苟道流正在成为穿越题材的新细分方向。整体来看，"穿越"作为万能母题，正与灵异、苟道、家族、学院等新流派深度结合，衍生出丰富细分赛道。

## 创作建议

**1. 深耕"都市灵异/悬疑"赛道**：本周《捞尸人》同时霸榜月票、畅销双第一，灵异标签（203次）与"灵异+穿越"共现（59次）均位居前列。建议创作者聚焦"都市背景下带有灵异悬疑元素的穿越/觉醒故事"，融合"捞尸""猎魔""渡劫"等具象职业设定，这是当前回报率最高的方向。

**2. 把握历史题材的"家族+权谋+经营"红利**：历史品类单周暴涨，且"家族""权谋""种田""苟道"等标签集中爆发。建议尝试"历史背景下的家族崛起/种田经营/权谋博弈"叙事，避开宏大战争，转向微观的人与家族成长，可结合年代文（1983、1984）唤起怀旧共鸣。

**3. 拥抱"轻小说+玩梗+二次元"的轻松向创作**：轻小说在书友榜、更新榜表现抢眼，且"以一龙之力""女仆""战锤女原体"等标题自带梗文化属性。建议创作者尝试轻松搞笑、二次元浓度高、带强烈梗和反差设定的作品，这类内容在年轻读者群体中传播力强、凝聚力高。

**4. 慎入玄幻/仙侠红海与衰退赛道**：玄幻、仙侠本周双双降温，诸天无限持续衰退，体育、军事、现实体量萎缩。若非要写玄幻/仙侠，建议走"精品化+差异化"路线（如《玄鉴仙族》的家族修仙、《没钱修什么仙》的反套路），而非跟风传统套路；对诸天无限、体育等衰退题材应谨慎投入。

## FAQ

**Q: 本周最火的品类是什么？热度第一的题材方向是什么？**
A: 从体量看是都市（251本）和轻小说（232本）；从热度增幅看，历史（+2.11）是本周最大黑马。综合创作风向，**都市灵异/悬疑**（以《捞尸人》为代表）是当前最火且回报最高的方向。

**Q: 玄幻、仙侠是不是不行了？还能写吗？**
A: 本周玄幻、仙侠热度分别下滑 1.86 和 1.89，确实在降温。但头部依然强势，《夜无疆》《星河之主》《玄鉴仙族》《没钱修什么仙》稳居月票榜前列。不是不能写，而是必须精品化、差异化，走反套路或细分流派（如家族修仙、苟道修仙），跟风传统套路很难出头。

**Q: 历史题材为什么突然火了？有什么代表作品？**
A: 历史品类单周热度暴涨 2.11，主要受头部作者带动。榴弹怕水的《廓晋》同时登上月票、畅销、阅读指数三大榜，其旧作《绍宋》也常驻收藏榜。历史+家族+权谋+种田的严肃向创作正被读者热捧，且年代文（1983、1984）带来怀旧共鸣。

**Q: 什么是"苟道流"？现在还有机会吗？**
A: "苟道"指主角苟且发育、稳健低调、不浪不装逼的创作风格，标签频次 74，且与"穿越"共现 39 次。《苟在两界修仙》登上阅读指数榜。当前苟道流与家族、种田、权谋结合，仍有较大创作空间。

**Q: 灵异题材为什么突然火了？**
A: 主要归功于《捞尸人》霸榜月票、畅销双第一，带火了"都市灵异/悬疑"赛道。灵异标签频次高达 203，"灵异+穿越"共现 59 次。创作者可关注"都市背景+灵异悬疑+职业化设定（捞尸、猎魔、渡劫）"的组合。

**Q: 轻小说现在值得入局吗？**
A: 很值得。轻小说体量第二（232本），热度持续上行（+1.19），且在书友榜、更新榜、阅读指数榜表现活跃。轻松搞笑、玩梗、二次元、反差设定的内容在年轻读者中传播力极强。

**Q: 本周榜单换手率 65.4% 意味着什么？**
A: 意味着榜单竞争极其激烈，每周近三分之二的作品会变动。对新作者是机会（新作易冲上榜），但也说明作品生命周期短，需要持续更新和高质量内容来维持热度。

**Q: 有哪些被忽视的小众题材值得关注？**
A: 武侠（连续数周升温至 2.25）、科幻（远瞳《异度旅社》上榜）值得关注。武侠虽体量小但增速稳定，科幻则借助头部作者回暖。此外"星际""学院""直播"等标签也保持一定热度。

**Q: "系统流"还流行吗？**
A: 依然流行，系统标签 405 次、"穿越+系统"共现 193 次居首。但纯系统流已饱和，建议将系统作为"金手指"与灵异、苟道、家族、学院等新流派结合，而非单独依赖。

**Q: 写年代文/怀旧文有市场吗？**
A: 有。关键词中"时代""未来""一年"高频，且《1984：从破产川菜馆开始》《重回1983：闽北往事》等年代文登上月票/更新榜。历史题材的升温也带动了年代怀旧叙事。

**Q: 诸天无限还能写吗？**
A: 建议谨慎。诸天无限热度已从 6.82 高位持续下滑至 3.02，连续多周在低位徘徊，是明显衰退的题材。除非有独特创新，否则不建议新人入局。

**Q: 我应该选哪个品类更容易出成绩？**
A: 结合体量、热度增幅和头部表现，**都市灵异、历史家族权谋、轻小说玩梗** 是当前性价比最高的三个方向。传统玄幻/仙侠赛道拥挤且降温，需精品化才能突围。

**Q: 头部作者（乌贼、辰东等）霸榜是否意味着新人没机会？**
A: 并非如此。榜单 65.4% 的高换手率恰恰说明中腰部作品也有大量上榜机会。头部作者占据的是月度积累型榜单（月票、畅销），而更新榜、书友榜等更偏好活跃的新内容，新人应聚焦更新速度与读者互动。

**Q: 本周关键词"斗罗""武魂"上榜，说明什么？**
A: 说明斗罗同人/衍生创作热度高（如《斗罗：转生神主日，多米尼克斯》登上更新榜）。经典 IP 的二次创作仍是流量入口，但需注意版权合规。
