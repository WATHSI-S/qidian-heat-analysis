# 起点中文网 2026-W42 排行榜深度风向分析报告

## 本周概览

本周（2026-W42）榜单共收录 **1260 条书籍记录**，去重后 **691 本独立作品**，来自 **583 位作者**，覆盖 **14 个品类**。七大榜单（月票、畅销、阅读指数、推荐、收藏、书友、更新）各 180 条，结构均衡，说明数据采样完整、可比性强。相比上周，市场呈现明显的"**回暖反弹**"特征：新增书籍 250 本、消失 77 本，周更替率高达 **63.1%**，反映出榜单流动性极强、新书冲击力旺盛，市场处于活跃换血期。

从品类体量看，**都市（236）、玄幻（228）、轻小说（207）、仙侠（171）** 构成第一梯队，四者合计占据榜单近七成席位；**历史（121）、科幻（77）、诸天无限（64）** 构成第二梯队。整体市场情绪可以用一句话概括：**头部品类集体反弹、腰部题材加速分化、短平快新书冲击加剧**。

值得注意的是，本周榜单呈现"**老牌大神稳坐头部、新书靠标签打法冲榜**"的双轨格局——月票榜前五由辰东《夜无疆》、季越人《玄鉴仙族》、田隶《武道！》等成熟作品把持，而更新榜、书友榜则被大量"穿越+系统"的快节奏新书占据。这种"头部固化、腰部混战"的结构，是本周最核心的市场信号。

## 题材风向

**第一梯队集体反弹，玄幻领涨。** 本周最大亮点是头部品类的全面回升。玄幻热度从上周 29.66 攀升至 **32.47（+2.8）**，重回近 21 周高位区间（历史峰值 W37 为 33.82）；都市从 22.57 反弹至 **25.09（+2.53）**，一举扭转了连续三周（W39–W41）的下滑颓势；历史更是从 10.25 强势拉升至 **12.97（+2.72）**，几乎收复此前失地。这三大品类的同步反弹，说明上周的低谷更可能是短期波动而非趋势性衰退，读者对传统主流题材的需求依然坚挺。

**历史品类是最值得警惕的"黑马"。** 历史题材本周涨幅（+2.72）仅次于玄幻，且从趋势线看，其热度在 W40–W41 触底（12.18→10.25）后快速反弹至 12.97，弹性极强。榜单上《廓晋》（榴弹怕水）、《北望江山》（孤独麦客）、《尸祸一六四四》等作品同时出现在月票、畅销、推荐、阅读指数四榜，说明历史题材正在从"小众精品"向"多榜通吃"转型。尤其"**年代文 + 历史 + 种田/权谋**"的复合打法（如《1984：从川菜馆开始》《1979黄金时代》）正在成为新的流量密码。

**诸天无限异军突起，增速第一。** 虽然绝对体量不大（热度 4.87），但**诸天无限本周涨幅 +2.23、书籍数从 34 暴涨至 64（近乎翻倍）**，是所有品类中弹性最强的。更新榜中《遮天：我以凡身，步步登帝》《同时穿越，我都要死了金手指才来》《诸天万界蹭车系统》《吞噬星空：我有一个加点系统》等作品密集上榜，清晰勾勒出"**同人/诸天 + 系统 + 穿越**"这一细分赛道的爆发。这背后是经典 IP（遮天、吞噬星空、斗罗）同人化改编需求的集中释放。

**承压品类：武侠与悬疑灵异。** 武侠热度从 1.87 跌至 **1.24（-0.62）**，是本周跌幅最大的品类，延续了长期低迷（近 21 周始终在 1–2 区间徘徊）；悬疑灵异也小幅下滑（-0.14）。这两个品类目前缺乏头部爆款带动，短期内难以形成规模效应。奇幻（+0.72）、科幻（+0.54）则温和回升，科幻在 W36–W38 高位后维持 8.7 的稳健水平，属于"低调但扎实"的品类。

## 关键词与流派洞察

**"穿越"是绝对统治级关键词。** 本周 TF-IDF 关键词中，"穿越"以 **0.0383 的权重、1498 次频次**断层领先，几乎是第二名"系统"（0.0231 / 663 次）的 2.3 倍。紧随其后的"觉醒（497）""重生（332）""修仙（238）""开局（196）""天赋（193）"构成了一条清晰的创作公式链：**穿越 / 重生 → 觉醒 / 系统 → 开局 / 天赋 → 修仙 / 打脸**。值得注意的是"**斗罗（149）**""**诸天（145）**""**大陆（145）**"三个词的高频出现，直接印证了同人/诸天赛道的火热——这是本周关键词层面最重要的新增信号。

**流派标签呈现"一超多强 + 长尾细分"格局。** 在 3900 条标签记录中，有标签书籍 2464 本。**"穿越"以 1309 次遥遥领先**，其后是"系统（527）""重生（312）""修炼（263）""灵异（246）""游戏（177）"。更值得关注的是**共现关系**："穿越+系统"共现 254 次（最强组合），"修炼+穿越"135 次，"灵异+穿越"74 次，"系统+重生"67 次。这说明**"穿越"已从题材标签演变为基础设施级母标签**，几乎可与任何子类型叠加。

**细分赛道信号明确。** 标签榜中"**苟道（85）**""**无敌流（93）**""**种田（65）**""**家族（80）**""**权谋（51）**""**灵气复苏（47）**""**凡人流（39）**"等标签的稳定出现，揭示了读者口味的细分走向：**"苟道流/苟住发育"与"无敌流"形成两极**（一个强调隐忍积累，一个强调碾压爽感），"家族流""种田流""凡人流"则代表了对"慢节奏、体系化成长"的稳定需求。共现中"穿越+苟道"达 44 次、"修炼+凡人流"34 次，印证了这两个方向正在获得结构性关注。

## 创作建议

**1. 押注"诸天/同人 + 系统"赛道，但需绑定强 IP 或强设定。** 诸天无限品类本周书籍数近乎翻倍、增速全品类第一，且关键词中"斗罗""诸天""大陆"高频出现。建议创作者切入经典 IP 同人（遮天、吞噬星空等）或构建"多世界穿梭 + 加点系统"的原创设定，重点突出"开局即高能、快速打脸"的节奏，这是当前更新榜、书友榜最容易冲榜的路径。

**2. 用"穿越 + 副标签"的复合公式切入主流品类。** 数据显示"穿越"是基础设施级标签（共现率极高），单纯写"穿越"已无差异化。建议采用"穿越 + 苟道""穿越 + 家族""穿越 + 种田""穿越 + 权谋"等复合打法，尤其**家族流（80）与苟道流（85）** 标签体量可观但爆款稀缺，存在明显的内容供给缺口，是差异化突围的良机。

**3. 关注"年代文 + 历史"的跨界红利。** 历史品类本周反弹力度强劲（+2.72），且《1984：从川菜馆开始》《1979黄金时代》《1985：从塔寨乡水利员开始》等"年代 + 行业 + 奋斗"作品在都市/历史双榜通吃。建议创作者将历史背景与具体行业（餐饮、影视、水利等）结合，用"时代红利 + 个人奋斗"的叙事替代传统权谋宫斗，降低阅读门槛、扩大受众面。

**4. 谨慎进入武侠与纯悬疑赛道，或做"类型融合"改造。** 武侠热度持续探底（1.24，全品类垫底），纯悬疑灵异也小幅下滑。若坚持这两个方向，建议做融合改造——例如"武侠 + 系统""悬疑 + 灵异 + 穿越"（"灵异+穿越"共现已达 74 次），借助强势母标签引流，避免在缺乏爆款带动的冷门品类中孤军奋战。

## FAQ

**Q: 本周最值得入手创作的是哪个品类？**
A: 从增速看首推**诸天无限**（书籍数近乎翻倍、增速全品类第一），从体量与弹性结合看推荐**玄幻、历史、都市**三大反弹品类。玄幻体量最大（228 本）且领涨，历史弹性最强，都市则刚扭转三周下滑。

**Q: "穿越"题材是不是已经饱和了？**
A: 从标签看"穿越"共现 1309 次、关键词权重断层第一，说明它是**基础设施级母标签而非独立赛道**。它不会饱和，但"只写穿越"没有差异化。真正的机会在于"穿越 + 细分副标签"的复合创新。

**Q: 系统流还有空间吗？**
A: 有。"系统"是第二大关键词（663 次）和第三大标签（527 次），且"穿越+系统"是最强共现组合（254 次）。但建议做系统玩法的微创新（加点、模拟器、供应商等），榜单上《我有一个修仙模拟器》《神宠供应商》正是此类变体的成功案例。

**Q: 历史题材为什么突然火了？**
A: 历史本周热度 +2.72 强势反弹，一是上周触底后的自然回补，二是"年代文 + 行业奋斗"（如《1984：从川菜馆开始》）打开了新叙事空间，让历史从"小众精品"走向"多榜通吃"。

**Q: 武侠还能写吗？**
A: 风险较高。武侠本周热度 1.24、跌幅全品类最大（-0.62），近 21 周长期在 1–2 低位徘徊，缺乏头部爆款。若坚持，建议做"武侠 + 系统/穿越"的融合改造。

**Q: 新手作者应该冲哪个榜？**
A: 从本周数据看，**更新榜和书友榜**对新书最友好——更新榜前列几乎全为"穿越+系统"快节奏新书（如《三国：末将俞涉，百世轮回》《重生2012，开局5个亿》），书友榜也以新锐作品为主。签约新书榜本周无有效数据返回。

**Q: 当前读者最吃哪一类爽点？**
A: 关键词链显示"觉醒→开局→天赋→打脸"是主流爽点路径；标签上"无敌流（93）"代表碾压爽感，"苟道（85）"代表隐忍积累后爆发。两极并行，说明读者既要即时爽感，也接受"苟住发育"的延迟满足。

**Q: 头部作品有哪些值得研究的样本？**
A: 月票榜前五《夜无疆》（辰东）、《玄鉴仙族》（季越人）、《武道！》（田隶）、《没钱修什么仙？》（熊狼狗）、《请勿高考时渡劫》（最白的乌鸦）是本周标杆；其中《玄鉴仙族》同时霸榜阅读指数、畅销、推荐、收藏多榜，是"仙侠 + 家族流"的典范。

**Q: 同人/诸天题材会不会有版权风险？**
A: 同人改编需注意 IP 授权边界。本周诸天赛道爆发明显（关键词"斗罗""遮天""吞噬星空"高频），但建议优先选择已开放同人生态或构建原创世界观，降低风险。

**Q: 家族流和种田流值得做吗？**
A: 值得。"家族（80）""种田（65）""凡人流（39）"标签体量稳定但头部爆款稀缺，共现中"修炼+凡人流"达 34 次，说明存在供给缺口。适合擅长慢节奏、体系化成长叙事的作者。

**Q: 本周市场整体是涨还是跌？**
A: 整体回暖。头部品类玄幻、都市、历史同步反弹，仅武侠、悬疑灵异小幅下滑。周更替率 63.1% 说明市场活跃度极高，新书冲击力强。

**Q: 都市题材该怎么写才不落俗套？**
A: 本周都市反弹（+2.53），成功样本集中在"年代 + 行业"（《1984：从川菜馆开始》《1979黄金时代》）和"都市 + 修仙/神通"（《请勿高考时渡劫》《以神通之名》）。建议避开纯都市日常，叠加时代背景或超自然元素。

**Q: 科幻题材前景如何？**
A: 稳健。科幻本周热度 8.7（+0.54），在 W36–W38 高位后维持扎实水平，属于"低调但稳定"的品类。《异度旅社》（远瞳）、《急急如律令》（黑山老鬼）是本周代表，适合有硬核设定能力的作者。

**Q: 完本老书为什么还在榜上？**
A: 收藏榜、阅读指数榜中大量完本经典（《诡秘之主》《斗破苍穹》《绍宋》《遮天》）长期霸榜，说明**经典 IP 的长尾价值极高**。这提示创作者：世界观扎实、可反复阅读的作品具有穿越周期的能力。

**Q: 本周最该警惕的市场信号是什么？**
A: 一是**同质化风险**——"穿越+系统"组合泛滥（共现 254 次），红海竞争激烈；二是**武侠品类持续萎缩**，若无创新不建议盲目进入；三是榜单 63.1% 的高更替率意味着新书生命周期短，需靠强钩子和稳定更新留住读者。
