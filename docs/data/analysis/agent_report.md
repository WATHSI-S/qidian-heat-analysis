## 本周概览

2026-W39 周，起点中文网八榜合计收录 1460 本书籍条目，去重后为 719 个独立书名、653 位独立作者，覆盖 14 个品类。从榜单结构看，各榜规模高度均衡：签约新书榜 200 本，月票榜、畅销榜、阅读指数榜、推荐榜、收藏榜、书友榜、更新榜各 180 本，说明平台在"新书孵化—核心付费—长尾口碑"三个层级上都有稳定的流量池。

本周市场整体情绪可以用"**头部稳态、腰部洗牌**"来概括。周环比数据显示，W38→W39 共有 511 本延续上榜、247 本新进榜、165 本掉榜，**换手率高达 60.9%**。这意味着近六成的榜单席位在两周内发生了更替，竞争烈度极高，但也说明新书有充足的突围窗口——只要选题与更新节奏对路，进入榜单并非遥不可及。

大盘热度方面，头部品类格局未变：玄幻（232 本）、都市（240 本）、轻小说（227 本）三强领跑，仙侠（181 本）、历史（111 本）构成第二梯队。值得注意的是，本周**玄幻热度环比 +1.22（31.53→32.75）领涨大盘**，而科幻则明显退潮（-1.04，9.26→8.22），一涨一跌之间透露出读者口味正在向"更硬核的东方幻想"回归。

## 题材风向

**玄幻重新夺回增长引擎的位置。** 从 18 周趋势看，玄幻热度长期在 28–34 区间震荡，W37 达到 33.82 的阶段高点，W38 短暂回落至 31.53 后，本周强势反弹至 32.75，且 book_count 由 224 回升至 232。月票榜前两名《夜无疆》（辰东）、《武道！》（田隶）均为玄幻，畅销榜前 20 中玄幻独占 8 席，推荐榜前 6 中玄幻占 4 席。头部作者（辰东、爱潜水的乌贼、会说话的肘子、飞天鱼、风凌天下）集体坐镇，说明玄幻仍是"大神蓄水池"和"月票决战地"。

**仙侠出现小幅降温，但结构性机会仍在。** 仙侠热度连续两周回落（22.45→21.87），book_count 从 187 降至 181。不过《玄鉴仙族》（季越人）表现极为亮眼——它同时拿下阅读指数榜第 1、畅销榜第 2、月票榜第 3、推荐榜第 3，是本周综合表现最强的作品之一。"家族流 + 修真"的组合正在被验证，这为仙侠赛道提供了差异化的破局样本。

**新兴与回暖品类值得重点关注。** 本周增幅榜上，游戏（+0.93）、体育（+0.81）、武侠（+0.29）、悬疑灵异（+0.32）集体上扬。其中体育品类 book_count 从 19 猛增至 31，热度创近 18 周新高（2.27），是一个典型的"小品类异动"信号；武侠在 W33、W35、W37 多次冲高后本周再度回到 1.95，说明"传统武侠复兴"并非昙花一现。相反，科幻（-1.04）、历史（-0.53）双双回落，科幻从 W36 的高点 9.21 一路下滑至 8.22，历史则跌至 11.46 的近期低位。

**"年代文"与"都市异闻"是都市赛道内部的暗线。** 都市整体热度基本持平（26.16→26.37），但榜单结构揭示了明确的细分偏好：月票榜/畅销榜上有《1984：从川菜馆开始》《请勿高考时渡劫》《以神通之名》，推荐榜上有《1980潮起潮落》《1979黄金时代》，书友榜上有《1980潮起潮落》《异常病理科》。可见"80/90 年代创业流"与"都市怪谈/职业流"正在成为都市品类里最活跃的两条支线。

## 关键词与流派洞察

**TF-IDF 关键词揭示了本周最底层的创作语法。** Top 20 关键词中，"穿越"以 0.0376 的权重、1391 次频次断层第一，几乎是第二名的近两倍；其后是"系统"（615 次）、"觉醒"（473 次）、"重生"（320 次）。这四大词构成了当前网文的"元设定四件套"——**穿越提供身份错位，系统提供成长外挂，觉醒提供能力起点，重生提供信息差优势**。值得注意的是，"开局"（185 次）、"发现自己"（151 次）、"意外"（190 次）三个叙事触发词同时入榜，说明"开局即高能 + 意外触发金手指"的黄金三章公式仍是主流。

**题材专属词方面，"修仙"（218 次）、"斗罗"（145 次）、"武魂"（137 次）、"诸天"（143 次）、"大陆"（140 次）集体上榜**，反映出三条并行的创作脉络：一是传统修仙（修仙、武魂、大陆），二是 IP 同人/衍生（斗罗、诸天），三是世界观搭建。其中"斗罗""武魂"的持续高热，与更新榜上大量《斗罗绝世：我，最后的天灾》《斗罗：转生菊花关，成就至高神王》等衍生作品相互印证——**同人衍生赛道依然是新人低成本起量的重要通道**。

**流派标签分布进一步佐证了"穿越+"的统治力。** 在 2309 本带标签书籍中，"穿越"以 1213 次高居榜首，覆盖率超过一半；"系统"489 次、"重生"301 次、"修炼"245 次紧随其后。共现关系上，"穿越+系统"以 234 次成为最强组合，其后是"修炼+穿越"（126）、"灵异+穿越"（69）、"系统+重生"（64）。这组数据清晰地描绘出当前市场的"爆款配方"：**穿越打底 + 系统/修炼提供成长线 + 灵异/游戏/无敌流等标签做差异化调味**。此外，"苟道"（80）、"种田"（61）、"权谋"（50）、"凡人流"（35）等"慢节奏/策略向"标签的稳定存在，说明在爽文主流之外，一批追求"稳扎稳打、智斗经营"的读者群体已经形成规模。

## 创作建议

**建议一：押注"玄幻 + 高概念设定"，抢占头部流量池。** 玄幻本周热度领涨（+1.22），且大神云集、月票榜前列被玄幻霸占，是流量与付费转化率最高的赛道。新人不必正面硬刚"夜无疆"式的传统热血，可尝试"玄幻 + 家族/苟道/无敌流"的复合设定，用差异化的成长逻辑切入。参考《玄鉴仙族》"家族流"的成功，把宏大世界拆解为可经营的家族/势力单元，是当前被验证有效的路径。

**建议二：深耕"穿越 + 系统"元设定，但要给出一个"记忆点标签"。** 数据显示"穿越+系统"组合高达 234 次共现，是绝对主流，但也意味着同质化严重。建议在标准配方上叠加一个高辨识度标签：如"穿越+灵异"（69 次共现，悬疑灵异本周逆势上涨 +0.32）、"穿越+游戏"（51 次，游戏品类本周热度 +0.93 领涨小品类）、"穿越+星际"（44 次）。用"一个词就能说清"的核心创意，在签约新书榜的激烈竞争中快速建立辨识度。

**建议三：抓住"年代创业文"与"都市职业流"的窗口期。** 都市品类内部，1980/1984/1979 等年代背景作品密集上榜，且《请勿高考时渡劫》拿下书友榜第 1、阅读指数榜第 2，说明"轻喜感 + 时代怀旧 + 逆袭"的组合极具人气。同时《异常病理科》《国民律师》等"职业流"作品在书友榜占位，提示"专业领域 + 都市异闻"是尚未饱和的蓝海。建议创作者把年代质感做扎实，用真实的历史细节和行业知识建立可信度。

**建议四：谨慎对待科幻退潮，转向"软科幻 + 幻想融合"。** 科幻热度连续两周下滑（-1.04），纯硬科幻的市场空间正在收窄。但从畅销榜看，《急急如律令》（黑山老鬼，科幻）、《异度旅社》（远瞳，科幻）仍稳居前列，说明"科幻外壳 + 悬疑/奇幻内核"的融合路线依然有效。建议科幻创作者弱化技术硬核度，强化世界观奇观与人物情感，向"悬疑科幻""末世求生"（末世标签 38 次）等更易共情的子类型靠拢。

## FAQ

**Q: 本周哪个品类最值得新人入局？**
A: 玄幻和都市。玄幻本周热度领涨（+1.22），流量池最大；都市内部"年代创业文"和"职业流"有明确上升势头，且头部竞争相对分散，新人更容易在细分赛道突围。

**Q: 换手率 60.9% 意味着什么？对新人是好是坏？**
A: 意味着榜单席位流动极快，近六成两周内更替。对新人是利好——说明榜单没有固化，只要选题对路、更新稳定，进入榜单的机会很大，但也意味着必须持续保持内容竞争力，稍有松懈就会掉榜。

**Q: "穿越"关键词权重这么高，是不是已经饱和了？**
A: 穿越是"元设定"而非"具体题材"，它更像是一个通用外壳。饱和的不是穿越本身，而是"穿越+系统+打怪升级"的无脑复制。建议把穿越作为起点，叠加独特标签（如灵异、游戏、星际）做差异化。

**Q: 仙侠热度在下滑，还值得写吗？**
A: 值得，但要选对子类型。《玄鉴仙族》证明"家族流修真"极具潜力。仙侠的基本盘（181 本、热度 21.87）依然稳固，只是传统"凡人流单主角升级"竞争激烈，建议转向家族、宗门经营、群像等新结构。

**Q: 本周表现最强的作品是哪本？**
A: 综合来看是《玄鉴仙族》（季越人），它同时位列阅读指数榜第 1、畅销榜第 2、月票榜第 3、推荐榜第 3，是唯一在四大核心榜都进前三的作品。玄幻侧的《夜无疆》（辰东）则拿下月票榜、畅销榜、推荐榜三榜第 1。

**Q: 体育品类本周暴涨，是机会吗？**
A: 是值得关注的小品类异动。体育 book_count 从 19 增至 31，热度创 18 周新高（2.27）。小品类竞争小、读者黏性高，但天花板也相对低，适合作为差异化切入或副线尝试，不建议作为唯一押注方向。

**Q: "斗罗""武魂"这类词频繁出现，说明什么？**
A: 说明同人衍生赛道依然活跃。更新榜上大量《斗罗》衍生作品说明这是新人低成本起量的重要通道。但同人作品受 IP 版权和读者审美疲劳影响，建议作为练手和积累读者，长期仍要转向原创世界观。

**Q: 科幻退潮，我写的科幻是不是没市场了？**
A: 不是没市场，而是要调整方向。纯硬科幻在收窄，但"科幻+悬疑/奇幻"的融合路线依然有效（如《急急如律令》《异度旅社》）。建议弱化技术硬核度，强化奇观与情感，向末世、悬疑科幻靠拢。

**Q: "苟道""种田""权谋"这些慢节奏标签有市场吗？**
A: 有，且形成了稳定的小众群体。苟道 80 次、种田 61 次、权谋 50 次的出现频次说明"智斗经营流"已具规模。这类作品爽感来得慢但读者忠诚度高，适合擅长细节和逻辑的作者。

**Q: 黄金三章该怎么写？数据有提示吗？**
A: 有。"开局""发现自己""意外"三个词同时进入 TF-IDF 前 20，说明"开局即高能 + 意外触发金手指"的公式仍是主流。建议第一章就完成身份设定（穿越/重生）、金手指引入（系统/觉醒）和第一个冲突钩子。

**Q: 历史品类回落，是不是不景气？**
A: 历史本周跌至 11.46（-0.53），属正常波动。但《廓晋》（榴弹怕水）仍拿下阅读指数榜第 3、推荐榜第 8，说明优质历史文依然有强口碑。历史品类对作者的知识储备要求高，门槛即壁垒，写得好反而更难被替代。

**Q: 轻小说 227 本，赛道怎么样？**
A: 轻小说稳居前三（热度 21.08，微涨 +0.24），是"二次元向 + 同人衍生"的聚集地。阅读指数榜前 15 中有 4 本轻小说，说明其读者活跃度高。适合擅长轻松日常、角色互动、玩梗的作者。

**Q: 更新榜和月票榜差异大吗？**
A: 差异很大。更新榜前列多为新人新书（《修仙界第一煞修》《华娱：我在娱乐圈刷宝箱》等），反映的是更新勤奋度；月票榜则是大神与成熟作品的战场。两者几乎不重叠，说明"更新量"和"付费忠诚度"是两个独立维度。

**Q: 如果只能选一个标签组合，推荐什么？**
A: 推荐"穿越+系统+差异化标签"。这是数据验证的最强组合（共现 234 次），但务必叠加一个记忆点标签，如灵异、游戏或星际，避免淹没在同质化红海中。

**Q: 完本老书为什么还在榜上？**
A: 收藏榜前 20 几乎全是完本经典（《诡秘之主》《灵境行者》《斗破苍穹》《绍宋》等），说明完本神作具有长尾收藏价值。这提示创作者：一部好作品的收益不止于连载期，完本后仍能持续吸引新读者，质量是长期资产。
