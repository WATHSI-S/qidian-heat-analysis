## 本周概览

2026-W36周，起点中文网排行榜呈现出**强劲的全面复苏态势**。本周总书籍数达1440本（较上周1260本增长14.3%），独立作者数攀升至759人（上周601人），覆盖14个品类，数据规模显著扩大。从市场情绪看，各主要品类热度普遍上涨，整体市场处于**扩张上行期**，读者活跃度与作品供给量同步提升。

本周品类竞争格局呈现"**双雄争霸**"局面：都市（277本，热度32.15）与玄幻（239本，热度32.01）以几乎持平的热度值领跑市场，轻小说（271本，热度26.55）以惊人的书籍数量紧随其后，仙侠（197本，热度22.17）稳居第二梯队。值得注意的是，本周出现了**高达97.2%的换手率**——新增书籍420本、消失262本，说明市场正在经历剧烈的作品迭代，大量新作涌入、旧作退出，竞争异常激烈。

从榜单表现看，《捞尸人》（纯洁滴小龙）以都市灵异题材**同时登顶月票榜和畅销榜双榜**，展现出极强的市场号召力。辰东的《夜无疆》、季越人的《玄鉴仙族》等玄幻、仙侠头部作品持续霸榜，而《诡秘之主》作为完本老作依旧稳居收藏榜第一，印证了经典IP的长尾价值。

## 题材风向

**都市题材强势回归，现实向+灵异向双轨并进。** 都市品类本周热度从27.18跃升至32.15（+4.97），为全品类最大增幅，书籍数也从249本增至277本。月票榜冠军《捞尸人》走的是"都市灵异+民俗怪谈"路线，而《1984：从破产川菜馆开始》《1980潮起潮落》《华娱93：从卖磁卡到娱乐大亨》等则代表了"年代创业/商战"这一现实向流派的兴起。签约新书榜中都市题材占据近半壁江山，且大量作品以"1980/1984/1993"等具体年代为背景，**"年代穿越+白手起家"正成为都市题材最炙手可热的新叙事模板**。

**轻小说异军突起，成为增长最快的第二引擎。** 轻小说本周热度从22.03升至26.55（+4.52），书籍数从220本暴增至271本，增幅在头部品类中仅次于都市。更新榜前十中轻小说占据三席（《孽徒，别破坏为师的飞升躺平梦》《宝可梦：开局神兽男》《同时穿越》系列），书友榜冠军《还不起学贷的我只好兼职猎魔》也是轻小说。轻小说的火热与"斗罗""宝可梦""战锤"等IP同人、二次元混搭题材的兴起密切相关，**"轻小说+IP二创+系统流"正在快速收割年轻读者**。

**仙侠走向"日常化+家族化"，玄幻头部稳固。** 仙侠品类热度从20.58升至22.17（+1.6），《玄鉴仙族》持续霸榜，其"家族流+苟道修仙"的叙事模式带动了"家族""苟道""凡人流"等标签的流行。玄幻品类热度32.01（+1.96），辰东《夜无疆》、爱潜水的乌贼《剑烛大荒》、会说话的肘子《青山》等大神作品形成稳定的头部矩阵，但**玄幻内部竞争白热化、新作突围难度大**。值得关注的是"苟道""无敌流"等反套路的"谨慎流"叙事在玄幻中持续升温。

**历史品类逆势下滑，成为唯一负增长的主要品类。** 历史热度从13.16降至12.10（-1.07），是本周唯一负增长的品类，但《廓晋》（榴弹怕水）和《绍宋》（完本）仍稳居各榜前列，说明**历史品类头部稳固但腰部供给不足**。此外，游戏品类（+1.7）、诸天无限（+1.46）、科幻（+0.92）均实现显著增长，尤其游戏品类热度翻倍（从2.38升至4.08），《浊世游戏》《我家客厅刷副本了》等新作表现亮眼。

## 关键词与流派洞察

TF-IDF关键词分析显示，**"穿越"（1251次）以压倒性优势位居第一**，"系统"（565次）、"觉醒"（436次）、"重生"（293次）构成第二梯队，这三大"金手指"叙事要素依然统治着网文创作的核心逻辑。"时代""开局""天赋""奖励"等高频词共同指向**"穿越+开局+天赋+奖励"的爽文公式**仍是最主流的创作范式。值得注意的是，"斗罗"（126次）和"武魂"（124次）的高频出现，印证了斗罗IP同人创作的持续热度。

流派标签分布进一步印证了这一趋势：**"穿越"（1085本）与"系统"（446本）的共现组合（216次）是全网最热门的叙事搭配**，"修炼+穿越"（113次）、"灵异+穿越"（65次）紧随其后。这揭示出三个核心创作方向：一是**"穿越+系统"的经典金手指组合**，二是**"灵异/民俗+穿越"的新兴混搭**，三是**"修炼+凡人流/苟道"的日常化修仙**。此外，"学院""星际""洪荒""种田""权谋"等标签的出现，说明细分赛道正在快速分化。

值得特别关注的是**"灵异"（214本）标签的异军突起**。"灵异+穿越""灵异+系统"的共现组合均进入前列，结合《捞尸人》登顶月票榜、《异常病理科》《被黄皮子讨封》等新作涌现，**"都市灵异/民俗怪谈"正在从边缘题材跃升为主流风口**。同时，"苟道"（76本）、"无敌流"（82本）等反套路标签的持续增长，反映出读者对"龙傲天"式主角的审美疲劳，转而青睐"谨慎苟活""扮猪吃虎"的差异化人设。

## 创作建议

**1. 深耕"年代穿越+白手起家"的都市现实流。** 本周签约新书榜中《1980潮起潮落》《1984：从破产川菜馆开始》《华娱93》等作品集体走红，说明读者对"穿越到具体年代、从零创业、见证时代变迁"的叙事有强烈需求。建议创作者以"改革开放年代+具体行业（餐饮/娱乐/制造业）+时代红利"为核心框架，强化年代质感与细节真实感，将"时代"这一关键词的价值最大化。

**2. 把握"都市灵异/民俗怪谈"这一新兴风口。** 《捞尸人》双榜登顶、《异常病理科》《被黄皮子讨封》等新作涌现，加上"灵异"标签214本的体量，都指向都市灵异正在成为下一个爆款赛道。建议以"都市日常+民俗怪谈+悬疑解谜"为骨架，结合"穿越/系统"等金手指要素，打造差异化作品。这一赛道目前供给尚不饱和，是**蓝海中的蓝海**。

**3. 轻小说+IP二创是快速起量的捷径。** 轻小说品类书籍数暴增、更新榜和书友榜表现突出，且大量作品依托"斗罗""宝可梦"等成熟IP进行二次创作。对于新作者而言，借助知名IP的流量红利、结合系统流和二次元风格，是**快速积累读者基础**的有效路径。但需注意IP版权合规，原创轻小说同样有爆发空间（如《还不起学贷的我只好兼职猎魔》）。

**4. 在成熟赛道中寻找"反套路"差异化切口。** 玄幻、仙侠虽为头部品类但竞争极度饱和，建议新作者避免正面硬拼大神作品。可借鉴"苟道""家族流""凡人流"等反套路叙事——如《玄鉴仙族》将修仙日常化、家族化，《这个武圣太谨慎了》主打"谨慎流"人设——在成熟框架中注入新鲜人设和世界观，以差异化突围。

**Q: "穿越"为何仍是第一关键词？**
A: "穿越"以1251次出现频率远超其他关键词，因为它是网文最基础的世界观切换装置，能自然衔接"系统""觉醒""重生"等金手指要素，且与"年代创业""灵异""修仙"等几乎所有题材都能融合，普适性极强。
