# 起点中文网创作风向分析报告（2026-W41）

## 本周概览

本周（2026-W41）榜单覆盖 1080 本书次、518 个独立书名、421 位独立作者，横跨 14 个品类，六大榜单（月票/畅销/阅读指数/推荐/收藏/书友）各 180 本，结构规整。从体量上看，玄幻（206）、都市（203）、轻小说（183）、仙侠（157）构成第一梯队，四者合计占据榜单的绝大部分，头部集中度依然很高。

整体市场情绪偏"降温"。环比上周（W40），榜单换手率高达 50.4%——248 本书跌出榜单、92 本新书进榜，说明榜单流动性极强、竞争白热化。更值得注意的是，几乎所有主流品类的热度值都在下滑：轻小说 -3.67、都市 -2.16、历史 -1.93、玄幻 -1.74，只有悬疑灵异（+0.34）、武侠（+0.31）、游戏（+0.12）逆势微涨。对比 W39 更能看出这是一轮"普跌"：都市 -3.81、玄幻 -3.09、轻小说 -1.99，头部大盘整体收缩。

这种"大盘降温 + 高换手"的组合，通常意味着读者注意力正在重新分配，老牌爆款的热度自然衰减，而新书尚在爬坡期。对创作者而言，这既是风险（大盘收缩），也是机会（榜单洗牌、新书更容易卡位）。

## 题材风向

**头部品类集体回调，但格局未变。** 玄幻、都市、轻小说、仙侠四强仍牢牢占据榜首位置，但本周全部走弱。轻小说从 W36 的高点（26.55）一路回落到 19.09，是近 20 周的低位区间；都市从 W22 的 32.9 跌至 22.57，创下近期新低；玄幻从 W37 高点 33.82 回落至 29.66。这更像是一次周期性回调而非结构性衰退——这些品类在 W36-W37 刚经历过高点，回调属于正常波动。

**逆势上涨的"小众品类"值得关注。** 悬疑灵异本周 +0.34，且近 5 周（W36-W41）稳定在 2.3-2.9 区间，较 W27-W30 的低谷（1.9-2.1）明显抬升，呈现温和上行趋势。武侠同样从 W40 的 1.55 反弹至 1.87，回到近 20 周的中上水平——武侠虽体量小（20 本），但"冒官锦衣，从满级太玄经开始"这类作品进入书友榜 Top20，说明传统武侠+系统流仍有细分受众。游戏品类小幅上涨至 3.22，在"游戏+穿越"标签共现 54 次的支撑下保持稳定。

**收缩最明显的品类需警惕。** 诸天无限连续走弱（W37 的 5.12 → W41 的 2.64，近乎腰斩），奇幻从 W40 的 4.75 跌至 3.65，历史从 12.18 跌至 10.25。诸天无限的下滑尤其明显，说明"多世界穿越缝合"这一套路可能正在透支读者新鲜感。奇幻的回落则与轻小说大盘走弱同步，二者受众重叠度高。

**值得关注的潜力方向：** 悬疑灵异 + 都市的结合（如《捞尸人》稳居畅销榜第 6）、科幻中的"旅社/异度"设定（《异度旅社》同时进入月票榜、阅读指数榜、推荐榜），以及"历史+权谋"（《廓晋》月票榜第 7、阅读指数榜第 9）。这些方向虽非大盘主流，但在榜单上表现稳定，属于"抗跌"型赛道。

## 关键词与流派洞察

**TF-IDF 关键词揭示"穿越 + 系统"仍是绝对核心。** 本周关键词榜首"穿越"权重 0.0379、频次 1439，遥遥领先；"系统"（0.0226/637）、"觉醒"（0.0178/487）、"重生"（0.0149/329）紧随其后。这四大母题构成了当前网文创作的"底层操作系统"。值得注意的是"修仙"（0.0107）、"开局"（0.0096）、"天赋"（0.0089）、"发现自己"（0.0081）等词的高频出现，反映出"开局即高光/觉醒天赋"的爽文节奏仍是主流写法。"斗罗""武魂""大陆"等词进入 Top20，说明唐家三少式 IP 的余温仍在，同人/衍生创作活跃。

**流派标签分布印证母题集中，但共现关系给出更细的配方。** 全球 3779 本书中，2382 本带标签，"穿越"以 1257 次断层领先（占带标签书籍的 53%），"系统"504、"重生"309、"修炼"255。最关键的洞察来自共现：**"穿越+系统"共现 244 次**，是绝对主流的组合；"修炼+穿越"132、"灵异+穿越"70、"系统+重生"64、"游戏+穿越"54。这说明单纯的"穿越"已不够，读者期待"穿越+X"的复合设定。

**几个上升中的细分配方值得注意：** "无敌流+穿越"（46）、"星际+穿越"（44）、"穿越+苟道"（43）、"学院+穿越"（39）、"洪荒+穿越"（38）、"家族+穿越"（36）。"苟道"（82 次）与"家族"（77 次）作为标签本身频次不低，且与穿越强绑定，暗示"稳健发育流"和"家族群像流"正在成为新宠。此外"种田"（62）、"权谋"（51）、"灵气复苏"（47）等标签的存在，说明"慢节奏/经营/权谋"类受众稳定。对比 W40，本周关键词与流派分布几乎完全一致，说明创作端母题结构高度稳定，变化主要发生在品类热度层面而非题材内核。

## 创作建议

**建议一：押注"穿越/系统 + 细分复合标签"，拒绝裸奔式穿越。** 数据显示"穿越"已是红海（53% 书籍带此标签），单靠穿越难以突围。应主动叠加高增长共现标签：苟道（+43）、家族（+36）、学院（+39）、星际（+44）。推荐方向为"穿越+家族+苟道"的稳健发育流，或"穿越+学院"的青春成长流，避开纯无敌流的审美疲劳。

**建议二：切入抗跌的悬疑灵异与"都市+灵异"赛道。** 悬疑灵异是本周唯一明显上涨的主流品类，且连续 5 周温和上行；《捞尸人》《神秘复苏》等作品在畅销榜表现稳健。建议创作"都市+灵异+穿越"或"民俗悬疑+系统"的复合题材，利用灵异标签 238 次的高基数和"灵异+穿越"70 次共现的成熟配方，在降温的大盘中抢占抗跌赛道。

**建议三：警惕诸天无限与纯奇幻，或做差异化改造。** 诸天无限近乎腰斩（5.12→2.64），纯奇幻跌至 3.65，说明"多世界缝合"与"传统西幻"套路正在透支。若要做，必须嫁接强设定：如"诸天+权谋"或"奇幻+学院+直播"等反套路组合，用标签差异化对抗品类衰退。

**建议四：把握高换手率带来的新书窗口期。** 本周换手率 50.4%，248 本书出榜、92 本新书进榜，说明榜单卡位机会大。新书应聚焦"开局节奏快、标签鲜明、共现组合清晰"的策略——关键词中"开局""觉醒""天赋"的高频印证了读者对"前 3 章即高潮"的偏好。建议新书在书名和简介中直接嵌入"穿越+系统+具体细分标签"的组合信号，提升在推荐榜、书友榜的曝光转化。

## FAQ

**Q: 本周大盘整体是涨还是跌？**
A: 整体偏跌。除悬疑灵异（+0.34）、武侠（+0.31）、游戏（+0.12）外，主流品类全线回调，都市 -2.16、轻小说 -3.67、历史 -1.93、玄幻 -1.74，属于头部大盘的周期性收缩。

**Q: 现在写穿越题材还来得及吗？**
A: 来得及，但必须做复合。53% 的带标签书籍都有"穿越"标签，纯穿越已是红海；应叠加苟道、家族、学院、星际等高增长共现标签形成差异化。

**Q: 哪个品类本周最值得切入？**
A: 悬疑灵异。它是唯一明显上涨的主流品类，连续 5 周温和上行，且"都市+灵异"组合在畅销榜有稳定表现，属于抗跌赛道。

**Q: 诸天无限为什么下滑这么厉害？**
A: 从 W37 的 5.12 跌到 W41 的 2.64，近乎腰斩。多世界缝合套路可能正在透支读者新鲜感，建议嫁接权谋等强设定做改造。

**Q: 最主流的标签组合是什么？**
A: "穿越+系统"共现 244 次，是绝对主流。其次是"修炼+穿越"132、"灵异+穿越"70、"系统+重生"64。

**Q: 轻小说为什么跌这么多？**
A: 从 W36 高点 26.55 回落到 19.09，属于高位回调。轻小说与奇幻受众重叠，二者本周同步走弱，需观察是否为趋势性变化。

**Q: 新手作者应该选大品类还是小众品类？**
A: 大品类流量大但竞争激烈、本周普跌；小众品类如悬疑灵异、武侠逆势上涨。建议新手切入抗跌的小众细分赛道，或在大品类中做复合标签差异化。

**Q: "苟道""家族"这类标签为什么值得关注？**
A: 苟道 82 次、家族 77 次，且分别与穿越共现 43、36 次，说明"稳健发育流""家族群像流"正在成为新宠，是差异化突围的好方向。

**Q: 榜单换手率 50.4% 意味着什么？**
A: 意味着极高的流动性——近一半书籍被替换，新书卡位机会大，但也说明老书热度衰减快，需要持续运营维持曝光。

**Q: 关键词里"开局""觉醒""天赋"高频说明什么？**
A: 说明读者偏好"前 3 章即高潮"的快节奏爽文。新书应在开篇快速给出金手指/觉醒设定，避免慢热。

**Q: 历史品类还值得写吗？**
A: 本周历史下跌（12.18→10.25），但《廓晋》仍稳居月票榜第 7、阅读指数榜第 9。历史+权谋属于抗跌细分，适合有考据功底的作者。

**Q: 科幻品类表现如何？**
A: 相对稳定，本周 8.17（微跌 -0.18），《异度旅社》《急急如律令》多榜在列。"科幻+旅社/异度"等设定型作品表现突出。

**Q: 完本老书为什么还在榜上？**
A: 《诡秘之主》《绍宋》《斗破苍穹》等完本经典仍占据收藏榜前列，说明长尾 IP 价值高。新书可借鉴其世界观深度与设定严谨性。

**Q: 本周最值得模仿的成功配方是什么？**
A: "穿越+系统+细分标签（苟道/家族/学院）"的复合设定，配合开局快节奏与鲜明标签，是当前验证度最高的创作配方。

**Q: 大盘降温时该观望还是出手？**
A: 建议出手。降温伴随高换手，正是新书卡位的窗口期；但应避开衰退品类（诸天无限、纯奇幻），聚焦抗跌赛道与复合标签。
